# 实现-包结构导览

- 状态：待校验
- 最后更新：2026-08-01
- 关联设计：[架构总览](../02-设计/架构总览.md)

本文从代码入口与依赖方向走查 monorepo 结构。仓库采用 pnpm workspace + Turbo 管理。

## 1. 顶层结构

| 路径 | 类型 | 说明 |
|------|------|------|
| `apps/core-service` | 应用 | 本机 API + Worker 编排 |
| `apps/desktop` | 应用 | Tauri 2 桌面壳 |
| `apps/ui` | 应用 | React 管理面板 |
| `packages/core` | 包 | 同步引擎与评论导入业务 |
| `packages/feishu` | 包 | 飞书开放平台适配 |
| `packages/git` | 包 | Git 访问与 hook |
| `packages/converter` | 包 | 文档格式转换 |
| `packages/db` | 包 | Drizzle schema 与数据访问 |
| `packages/shared` | 包 | 共享类型、契约与工具 |
| `scripts` | 目录 | 调试与探测脚本 |
| `fixtures` | 目录 | 测试夹具 |

## 2. 依赖方向

```text
apps/core-service
  ├── packages/core
  ├── packages/feishu
  ├── packages/git
  ├── packages/db
  └── packages/shared

packages/core → packages/{feishu, git, db, shared}
packages/feishu / git / db / converter → packages/shared
```

依赖单向流动：`apps → packages/core → 各能力包 → shared`。核心包不反向依赖应用。

## 3. 各包入口与关键文件

| 文件 | 职责 |
|------|------|
| `src/engine.ts` | `runSync` 同步主入口 |
| `src/comment-import.ts` | `runCommentImport` 评论导入主入口 |
| `src/sync/factory.ts` | 按同步模式创建规划器 |
| `src/sync/planner.ts` | 同步计划类型与规划器接口 |
| `src/sync/workspace-planner.ts` | 工作区模式规划 |
| `src/sync/repository-planner.ts` | 仓库模式规划 |
| `src/sync/repair-missing-nodes.ts` | 缺失节点补建操作 |
| `src/sync/overview-whiteboard.ts` | 同步文档总览画板 |
| `src/sync/sync-progress.ts` | 阶段进度上报 |
| `src/sync/sync-content.ts` | 可同步文档内容读取 |
| `src/errors.ts` | `BindingTaskPreemptedError` 等错误类型 |

|------|------|
| `factory.ts` | `LocalGitProvider` / `CloudGitProvider` |

### apps/core-service

| 文件 | 职责 |
|------|------|
| `src/app.ts` | Hono 路由装配 |
| `src/index.ts` | 进程入口 |
| `src/config.ts` | 环境配置 |
| `src/scheduler.ts` | `SyncQueue` 队列 + `Scheduler` 定时器 |
| `src/sync-coordinator.ts` | 同步任务协调（入队、抢占、执行、播报） |
| `src/comment-import-coordinator.ts` | 评论导入协调 |
| `src/binding-task-registry.ts` / `binding-task-preempt.ts` | 任务登记与代际抢占 |
| `src/bot/` | 机器人长连接、指令处理、播报、安静模式 |

## 4. 约定

- 包间引用一律 `@feishu-md/<name>` 包名，不使用相对路径跨包导入；
- `apps/ui` 通过 HTTP 与 core-service 通信，不直接 import 其它包；
- 调试脚本放在 `scripts/`（探测飞书接口行为），不属于运行时依赖。

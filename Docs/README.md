# Docs 文档库

本目录是 Feishu MD Repo 的正式文档库，按「需求 → 设计 → 实现」三层组织，每层回答一个核心问题：

| 层 | 目录 | 回答的问题 |
|----|------|-----------|
| 规范 | [00-规范](./00-规范/README.md) | 术语与写作如何统一 |
| 需求 | [01-需求](./01-需求/README.md) | 需要解决什么问题 |
| 设计 | [02-设计](./02-设计/README.md) | 如何满足这些需求 |
| 实现 | [03-实现](./03-实现/README.md) | 程序如何实现系统 |

## 阅读路径

- **想了解项目全貌**：从 [01-需求/需求总览](./01-需求/需求总览.md) 开始，按需求 → 设计 → 实现顺序读。
- **想理解某个机制为什么这么做**：读 [02-设计/决策记录](./02-设计/决策记录/README.md) 中的 ADR。
- **想参与开发**：先读 [03-实现/实现-包结构导览](./03-实现/实现-包结构导览.md)，再对照 [03-实现](./03-实现/README.md) 各篇。
- **遇到不认识的术语**：查 [00-规范/词条库](./00-规范/词条库.md)。

## 本目录索引

| 名称 | 类型 | 说明 |
|------|------|------|
| [00-规范](./00-规范/README.md) | 文件夹 | 词条库与文档写作规范 |
| [01-需求](./01-需求/README.md) | 文件夹 | 需求文档（含非功能需求） |
| [02-设计](./02-设计/README.md) | 文件夹 | 架构设计、决策记录（ADR）、数据模型、API 契约 |
| [03-实现](./03-实现/README.md) | 文件夹 | 包结构、同步流水线、队列与抢占 |

## 文档约定

- 需求与设计之间通过「需求编号」建立追溯：设计文档须注明其满足的需求条目。
- 设计决策记录在 [02-设计/决策记录](./02-设计/决策记录/README.md)，新增架构决策一律追加 ADR。
- 编写规则详见 [00-规范/文档写作规范](./00-规范/文档写作规范.md)。

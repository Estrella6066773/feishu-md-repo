# 设计-评论导入

- 状态：待校验

- 覆盖需求：[需求-评论回流](../01-需求/需求-评论回流.md)（R-comment-*）

## 1. 流程

评论导入由 `packages/core` 的 `runCommentImport` 执行，协调器为 `apps/core-service/src/comment-import-coordinator.ts`：

1. 读取绑定的全部文档映射（排除 `__sync_overview__` 保留路径）；
2. 对每个文档：拉取评论（含回复、划词引用、表情）；
3. 无评论 → 删除本地已有导出文件；
4. 有评论且与上次导出内容一致 → 跳过写入；
5. 有变化 → 写入 `.feishu/comments/` 下对应文件，更新导入清单；
6. 清理飞书侧已删除文档对应的本地导出与清单记录。

## 2. 数据落盘

| 项 | 路径 |
|----|------|
| 评论导入清单 | 仓库 `.feishu/comments/` 清单文件 |
| 单文档评论导出 | 按文档路径存放的评论导出文件 |

导出文件带 schema 版本号（`FEISHU_COMMENT_EXPORT_SCHEMA_VERSION`），内容比对用于增量跳过。

## 3. 触发与联动

- 触发来源：`schedule` / `manual` / `bot`；
- 定时联动：绑定开启 `commentImportOnSchedule` 时，定时检查同步连带导入评论；
- 与同步任务共享同一队列与抢占机制。

## 4. 日志

每次导入写入 `comment_import_logs`：文档数、评论数、回复数、状态、失败文档清单（[R-comment-10](../01-需求/需求-评论回流.md)）。

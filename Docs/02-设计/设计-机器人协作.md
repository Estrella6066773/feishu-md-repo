## 1. 组件划分

| 组件 | 文件 | 职责 |
|------|------|------|
| 机器人管理器 | `bot/manager.ts` | 长连接生命周期、事件分发 |
| WS 监听器 | `bot/ws-listener.ts` | 飞书事件接入（`im.message.receive_v1`） |
| 指令处理器 | `bot/command-handler.ts` | 指令解析与权限判定 |
| 播报器 | `bot/broadcaster.ts` | 同步结果播报、话题回复、安静模式 |
| 安静话题 | `bot/quiet-thread.ts` | 固定话题创建与维护 |

## 2. 播报流程

同步完成后 `SyncCoordinator` 调用 `broadcaster.notifySyncFinished`：

1. 按播报目标策略筛选（绑定级覆盖全局；未配置回退全局）；
2. 主消息：成功/失败摘要（绑定名、触发、Commit、文件数、操作数）；
3. 群支持话题时：按 commit 发送话题回复 + 文件列表（已映射文档带链接）；
4. 群不支持话题（错误码 230071）时仅发主消息；
5. 安静模式：写入固定话题（`quietThreadId` / `quietRootMessageId` 持久化）。

## 3. 指令与权限

- 指令：`同步` / `status` / `导入评论` 等，由命令解析器处理；
- 群聊默认须 @ 机器人（`commandRequireMentionInGroup`，可关闭）；
- 白名单：`commandAllowedChatIds` 限制群；`defaultBindingId` 指定默认绑定；
- 权限判定按用户权限级别（管理员/管理者/成员/黑名单/默认组），不再使用 `open_id` 白名单；未配置权限名单时回退旧版逻辑。

## 4. 机器人档案

- 设置页可配置多个机器人档案（appId + appSecret），`defaultBotId` 指定监听 WS 使用的默认机器人；
- 绑定可通过 `botId` 引用指定机器人，未指定用系统默认。

## 5. 权限级别矩阵

| 级别 | 可用能力 |
|------|----------|
| 管理员 | 全部绑定与全部指令（含完全重新搭建） |
| 管理者 | 仅对已指定绑定使用全部指令 |
| 成员 | 仅对有云仓库绑定发起普通同步 |
| 黑名单 | 禁用一切机器人功能 |
| 默认组 | 未写入名单的用户，无法使用指令 |

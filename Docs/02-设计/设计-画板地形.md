# 设计-画板地形

- 状态：待校验
- 最后更新：2026-08-03
- 覆盖需求：[需求-工具箱](../01-需求/需求-工具箱.md)（R-tool-05 / R-tool-06）

## 1. 目标

把飞书画板当作地形设计稿：用户在画板中用**指定颜色**的圆形与矩形排布关卡地形，工具箱读取画板节点，识别指定颜色的圆与矩形，导出几何体 JSON；Unity 侧用预配置好的墙体预制体复刻到场景中。

## 2. 画板结构要点

飞书画板由 `whiteboardNode` 构成，本功能只关注基础图形节点：

| 字段 | 说明 |
|------|------|
| `type` | 节点类型，基础图形为 `composite_shape` |
| `composite_shape.type` | 形状细分：`ellipse`（圆形）、`rect`（矩形）、`round_rect`（圆角矩形） |
| `style.fill_color` | 填充色，十六进制 RGB（如 `#6db5a3`） |
| `x / y` | 相对画布坐标（px），y 向下为正；**所有形状均以「旋转前包围盒的左上角」为锚点** |
| `width / height` | 宽高（px），为旋转前未旋转尺寸 |
| `angle` | 旋转角（度），绕形状质心旋转 |

## 3. 识别规则

- **形状**：只保留 `ellipse`（→ 圆形墙体）与 `rect` / `round_rect`（→ 矩形墙体），其余形状忽略。
- **颜色**：用户指定一组颜色（十六进制，大小写不敏感）。仅当节点的 `style.fill_color` 匹配指定颜色时才保留；颜色不匹配的几何体剔除。

## 4. 数据流

```text
飞书画板 --whiteboardNode.list--> 工具箱(core-service) --识别过滤--> 几何体 JSON
几何体 JSON --BoardTerrainImporter--> Unity 场景(ShipBuild)
```

### 4.1 飞书侧（packages/feishu）

- 新增 `board-terrain.ts`，导出 `extractBoardTerrainShapes(client, whiteboardId, colors)`。
- 读取画板全部节点，按上述规则过滤，输出 `BoardTerrainShape[]`。
- 复用现有 `listWhiteboardNodes()` 读取节点。

### 4.2 core-service

新增 `POST /api/toolbox/board-terrain/extract`：

| 请求字段 | 类型 | 说明 |
|----------|------|------|
| `boardUrl` | string | 画板直链（`…/board/<token>`）或含画板的云文档链接（`…/docx/…` / `…/wiki/…`）；工具运行时可填，二选一 |
| `whiteboardId` | string | 画板 ID；二选一，优先于 `boardUrl` |
| `colors` | string[] | 指定颜色（十六进制，可带 `#`，不区分大小写） |

> 云文档链接由 `resolveBoardTerrainWhiteboardId` 在文档正文中定位第一个画板块，再取其 `whiteboard_id` 读取节点。

返回：

| 字段 | 类型 | 说明 |
|------|------|------|
| `ok` | boolean | 是否成功 |
| `shapes` | BoardTerrainShape[] | 识别出的几何体 |
| `totalNodeCount` | number | 画板节点总数 |
| `matchedShapeCount` | number | 形状命中数（未按颜色过滤前） |

### 4.3 Unity 侧（Editor 工具脚本）

新增 `Assets/Scripts/Tools/Editor/BoardTerrainImporter.cs`：

- 菜单入口 `Tools/画板地形/从 JSON 生成（窗口）`，弹出复刻窗口；
- 读取几何体 JSON，加载 `Assets/Prefabs/Modules/Wall/Circle.prefab`（圆形）与 `Square.prefab`（矩形）；
- **锚点约定**：画板所有形状（圆/椭圆/矩形）的 `x/y` 均为旋转前包围盒的左上角，质心需按公式换算：
  `质心 = (x, y) + R(-angle) · (width/2, height/2)`（`R(θ)` 为二维旋转矩阵）；
- 画板坐标 y 向下，转 Unity 世界坐标 y 向上（取负），并按 `width/height` 与「像素换算单位」设置 `localScale`；
- 生成的墙体放入场景根节点「画板地形」下，可合并或重建该根节点。

## 5. 数据模型

```ts
interface BoardTerrainShape {
  /** 画板节点 ID */
  id: string;
  /** 形状类型：ellipse 或 rect（round_rect 归为 rect） */
  kind: 'ellipse' | 'rect';
  /** 颜色值（保留 #，小写） */
  color: string;
  /** 画板坐标 x（px） */
  x: number;
  /** 画板坐标 y（px，向下为正） */
  y: number;
  width: number;
  height: number;
  angle: number;
}
```

## 6. 与现有系统的关系

- 依赖 `packages/feishu` 的画板节点读取能力；
- 新增能力登记到 `packages/shared` 的 `CORE_API_FEATURES`，并递增 `CORE_API_VERSION`；
- UI 工具箱新增「画板地形」工具页，交互模式沿用现有工具箱工具。

## 7. 非目标

- 不做颜色到预制体的映射表：颜色仅用于过滤，形状决定用圆形还是矩形墙体预制体；
- 不自动同步画板变更到 Unity，导出 JSON 由用户手动导入。

# 需求-同步

- 状态：待校验
- 最后更新：2026-08-01

本文定义同步主链路的需求条目。设计实现见 [设计-同步引擎](../02-设计/设计-同步引擎.md)。

## 绑定配置

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-sync-01 | 支持创建、修改、删除绑定；绑定交叉三个维度：来源（本地/有云）× 模式（工作区/仓库）× 目标（Wiki/Drive） | 必须 | 面板可完成绑定 CRUD，字段校验通过 |
| R-sync-02 | 每个绑定可配置触发方式（提交 hook、定时、手动）、忽略规则、强制更新 glob、绑定级播报目标 | 必须 | 保存后按配置生效 |
| R-sync-03 | 有云库（`cloud`）绑定须配置远程 URL 与分支，同步时先 `fetch` 再读远程分支 | 必须 | 有云库提交新内容后，定时同步可拉到最新 |
| R-sync-04 | 本地库（`local`）绑定读本地 `HEAD`，不 fetch 远程；可安装 `post-commit` hook | 必须 | 本地提交后触发自动同步 |

## 同步模式与路径筛选

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-sync-05 | 工作区模式默认同步 `.md`/`.markdown` 与 `.csv`；非 Markdown 默认不同步（`mirrorNonMdFiles: false`） | 必须 | 仅预期扩展名被同步 |
| R-sync-06 | 仓库模式：每个含 README 的目录 → 飞书一篇文档（正文 README，标题为目录名）；独立 Markdown/CSV 作为单独文档 | 必须 | 目录结构在飞书侧正确嵌套 |
| R-sync-07 | 路径筛选两重：Git 规则（`git ls-files --with-tree` + `export-ignore`）＋ 项目规则（绑定 `ignoreGlobs`；系统默认排除 `node_modules` 与 `.git`） | 必须 | 被忽略路径不进入同步 |
| R-sync-08 | Wiki 目标支持 `space_id` + 可选父 `node_token`，子文档通过父节点嵌套 | 必须 | 文档挂载到指定父节点下 |
| R-sync-09 | Drive 目标仅支持 `folder_token`（`fld` 开头），不支持用文档 token 作父节点 | 必须 | 非 `fld` 前缀报错并提示 |

## 同步执行

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-sync-10 | 同步按阶段推进并上报进度：`planning → structure → content → cleanup → overview → done` | 必须 | 面板可看到当前阶段与进度 |
| R-sync-11 | 支持手动同步、完全重新搭建（修复同步）、强制重写正文 | 必须 | 三种操作行为符合定义 |
| R-sync-12 | 立即同步/机器人同步时按父节点子数量检测飞书侧缺失的已映射文件并自动补建 | 期望 | 缺失节点被补建 |
| R-sync-13 | 正文用官方 Markdown convert + 分段插入；本地/Git 图片读二进制写入 Image Block；不镜像云空间、不保留 GitHub 链接 | 必须 | 正文与图片在飞书可读 |
| R-sync-14 | 文内 Mermaid / flowchart 代码块 → 插入画板块并用 API 绘制 | 必须 | 图表正确渲染 |
| R-sync-15 | GFM 表格与 CSV → 原生表格；Drive 目标下可选择上传原文件（`tabularSyncMode: drive_file`） | 必须 | 表格正确写入 |
| R-sync-16 | 节点映射持久化，跨同步复用 token，避免每次重建 | 必须 | 二次同步不重建既有节点 |
| R-sync-17 | 同步结束后更新根级「同步文档总览」画板思维导图 | 必须 | 总览反映最新结构 |
| R-sync-18 | 仓库模式：删除 Git 中已不存在的文件时，清理飞书侧对应节点与本地映射 | 必须 | 飞书侧不再残留已删除文档 |
| R-sync-19 | 强制更新 glob 指定路径在每次同步都重写正文，不受内容哈希跳过逻辑影响 | 期望 | 命中 glob 的文档每次都写入 |
| R-sync-20 | 工作区模式 CSV 若配置 `drive_file` 但目标是 Wiki，自动回退为原生表格并告警 | 期望 | 日志出现回退告警，同步不中断 |

## 同步消息语义

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-sync-21 | 无变化时给出明确消息：增量无操作、补缺无操作、强制重写完成等 | 必须 | 完成日志与消息准确 |
| R-sync-22 | 空树或无可同步文件时给出可操作的错误提示 | 必须 | 报错信息包含路径/分支排查提示 |

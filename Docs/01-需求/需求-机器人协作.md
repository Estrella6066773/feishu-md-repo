# 需求-机器人协作

- 状态：待校验
- 最后更新：2026-08-01

本文定义机器人播报与指令的需求条目。设计实现见 [设计-机器人协作](../02-设计/设计-机器人协作.md)。

## 播报

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-bot-01 | 同步成功后向配置的播报目标推送成功消息，包含绑定名、触发来源、Commit 短哈希、文件数与操作数 | 必须 | 群/用户收到格式化主消息 |
| R-bot-02 | 群支持话题时，按 commit 发送话题回复（标题 + commit 说明原文），并附文件列表（已映射文档带链接） | 必须 | 话题内详情完整 |
| R-bot-03 | 群不支持话题（飞书错误码 230071）时只发主消息，不发送话题详情 | 必须 | 无异常报错 |
| R-bot-04 | 同步失败时推送失败消息并附错误信息 | 必须 | 失败消息准确 |
| R-bot-05 | 播报目标可配置范围策略：成功/失败、限定触发来源（git/schedule/manual/bot） | 期望 | 按策略过滤播报 |
| R-bot-06 | 绑定级播报目标覆盖全局；未配置时回退全局目标 | 必须 | 优先级正确 |
| R-bot-07 | 安静模式：机器人创建锚点消息并维护固定话题，后续播报全部写入话题，不在群会话刷屏 | 期望 | 群会话仅出现一次锚点 |
| R-bot-08 | 安静模式在群不支持话题时自动回退普通播报；关闭后再次开启会重建话题 | 期望 | 回退与重建行为正确 |

## 指令

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-bot-09 | 飞书长连接监听群内指令（如 `同步` / `status` / `导入评论`） | 必须 | 指令可触发对应动作 |
| R-bot-10 | 群聊中默认须 @ 机器人 才响应（可配置关闭） | 必须 | 未 @ 时不响应 |
| R-bot-11 | 可配置指令白名单群 `chat_id`；空表示不限制 | 期望 | 白名单外群不响应 |
| R-bot-12 | 可配置「同步」指令默认绑定的绑定；为空则同步全部 | 期望 | 指令行为正确 |

## 用户权限

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-bot-13 | 用户权限分五级：管理员 / 管理者 / 成员 / 黑名单 / 默认组 | 必须 | 各角色指令范围正确 |
| R-bot-14 | 管理员：全部绑定与全部指令（含完全重新搭建） | 必须 | 无限制 |
| R-bot-15 | 管理者：仅对已指定绑定使用全部可用指令 | 必须 | 未指定绑定不可操作 |
| R-bot-16 | 成员：仅可对有云仓库绑定发起普通同步；不可操作本地库、不可完全重新搭建 | 必须 | 越权操作被拒绝 |
| R-bot-17 | 黑名单：禁止一切机器人功能；默认组：未在名单中的用户无法使用指令 | 必须 | 拒绝行为正确 |
| R-bot-18 | 群聊中响应指令依据用户权限级别判定，不再使用 `open_id` 白名单；未配置权限名单时回退旧版白名单逻辑 | 必须 | 判定符合定义 |

## 机器人档案

| 编号 | 需求 | 优先级 | 验收标准 |
|------|------|--------|----------|
| R-bot-19 | 支持配置多个机器人档案（appId + appSecret），绑定可按 ID 指定使用的机器人 | 期望 | 绑定使用指定机器人 |
| R-bot-20 | 指令监听 WS 固定使用默认机器人档案 | 必须 | 长连接使用默认机器人 |

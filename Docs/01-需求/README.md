# 01-需求

本目录回答「需要解决什么问题」。需求条目以 `R-主题-序号` 编号，供设计层引用追踪。

| 名称 | 类型 | 说明 |
|------|------|------|
| [需求总览](./需求总览.md) | 文件 | 问题背景、目标、范围与非目标 |
| [需求-同步](./需求-同步.md) | 文件 | 同步主链路（工作区/仓库模式、正文、图表、表格） |
| [需求-机器人协作](./需求-机器人协作.md) | 文件 | 播报、指令、用户权限 |
| [需求-评论回流](./需求-评论回流.md) | 文件 | 飞书评论导入仓库 |
| [需求-工具箱](./需求-工具箱.md) | 文件 | 导出 Markdown、图表格式化、画板地形提取 |
| [非功能需求](./非功能需求.md) | 文件 | 安全、性能、可靠性、可观测性 |

## 需求编号规则

- 主题缩写：同步 `sync`、机器人 `bot`、评论 `comment`、工具箱 `tool`、总览 `overview`。
- 每个需求条目格式：`R-<主题>-<两位序号>`，如 `R-sync-01`。
- 设计文档引用时写全编号并加链接。

# 词条库

本文档登记 Feishu MD Repo 文档与代码中的定型术语，作为全库权威定义。新增术语时在此登记。

## 核心概念

| 术语 | 定义 |
|------|------|
| 绑定（Binding） | 一次「仓库 ↔ 飞书位置」的配置，交叉来源、模式、目标三个维度 |
| 同步模式 | 工作区模式（默认同步 `.md`/`.csv`）或仓库模式（每目录 README → 一篇文档） |
| 来源（sourceType） | 本地库（`local`，读本地 HEAD）或有云库（`cloud`，先 fetch 远程分支） |
| 目标（FeishuTarget） | 飞书知识库（Wiki，推荐）或云空间（Drive） |
| 触发（Trigger） | 同步启动来源：git 提交 / 定时 / 手动 / 机器人指令 |
| 节点映射（NodeMapping） | Git 路径与飞书节点 token 的持久对应关系 |
| 同步文档总览 | 同步结束时在飞书根级更新的画板思维导图（保留路径 `__sync_overview__`） |
| 修复同步（fullResync） | 全库结构检查，按飞书块特征校验后仅重写异常正文 |
| 强制重写 | 配合修复同步，跳过飞书块特征校验、重写全部正文 |
| 补建缺失节点（repairMissingRemote） | 立即同步/机器人同步时按父节点子数量检测飞书侧缺失的已映射文件并自动补建 |
| 评论导入 | 从已同步文档拉取评论（含回复、划词引用、表情），增量写入仓库 `.feishu/comments/` |
| 播报目标 | 机器人推送同步结果的目标（群聊或用户），可带独立策略 |
| 安静模式 | 全部播报写入机器人维护的固定话题，不在群会话时间线刷屏 |
| 机器人档案（FeishuBotProfile） | 设置页配置的飞书机器人（appId + appSecret），项目绑定可按 ID 引用 |
| 用户权限级别 | 管理员 / 管理者 / 成员 / 黑名单 / 默认组，决定机器人指令可用范围 |

## 同步操作类型

| 术语 | 定义 |
|------|------|
| ensure_folder | 确保飞书侧存在文件夹节点（不存在则创建） |
| ensure_doc | 确保飞书侧存在文档节点（不存在则创建） |
| update_doc | 更新既有文档节点 |
| delete | 删除飞书侧已不存在于 Git 树的节点（清清理阶段） |
| move | 节点迁移（规划器预留，当前实现中以删除+重建等价完成） |

## 路径与数据

| 术语 | 定义 |
|------|------|
| 保留同步路径 | `__sync_overview__`，同步文档总览的映射路径，不属于 Git 路径 |
| 正文哈希（contentSha） | 正文 Markdown 叠加图片 blob 的 SHA-256，含版本号（`image-sync-v13` 等），用于判断内容是否变化 |
| 评论导入清单 | `.feishu/comments/` 下的导入清单与按文档存放的评论导出文件 |

## 画板与图表

| 术语 | 定义 |
|------|------|
| 画板（Board） | 飞书云文档内的白板块，由 whiteboard_node 组成 |
| 画板几何体 | 画板节点中可映射为 Unity 地形元素的形状（圆 / 矩形） |
| 地形提取 | 从画板读取节点，按形状与指定颜色过滤并输出几何体列表的过程 |
| 墙体预制体 | Unity 项目中预配置的圆形 / 矩形墙体（`Assets/Prefabs/Modules/Wall/`） |

## 常量

| 术语 | 值 |
|------|-----|
| 默认定时检查间隔 | 10 分钟 |
| 定时检查最小/最大间隔 | 1 / 1440 分钟 |
| 核心 API 版本号 | `CORE_API_VERSION = 7` |
| 队列积压告警阈值 | 队列深度 ≥ 10 |
| 强制重写时的正文写入并发 | 1（串行） |
